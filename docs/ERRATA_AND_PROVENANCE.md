# Происхождение данных и ограничения комплекта

В исходном starter kit есть ссылки на этот документ, но самого файла не было. Эта запись добавлена при реализации приложения, чтобы зафиксировать доступную информацию, и **не является уточнением организатора**.

- Контрольная база — включенные в репозиторий `data/*.csv`, `scenarios/*.yaml` и правила в README и docs. Эти значения сохранены.
- `data/README.md` ссылается на исходную постановку DOCX, уточнения для жюри и анкету XLSX. Эти первичные файлы в доступном комплекте отсутствуют; их содержание независимо не проверялось.
- Начальный запас, конкретный перевод месяцев в дни, повторные поставки Earth-New и трактовка базового использования Emergency требуют явных допущений. Принятые правила описаны в [документации приложения](APPLICATION.md).
- README одновременно упоминает демонстрацию будущего периода в сдаче и называет 2041 необязательным. Приложение включает отдельную исследовательскую копию с 2041.
- Проверка `check_no_ready_solution` предназначена для чистого организаторского starter kit. Для участнического приложения применяется флаг `--participant`; проверки контрольных данных и арифметических векторов сохраняются.

Исследовательские коэффициенты и результаты приложения не объявляются условиями организатора или прогнозами реальной космической отрасли.
